# QQ Codex Pet

A fan-made Codex pet inspired by the classic QQ Penguin mascot.

This project was created as a personal side project for fun and experimentation with Codex pets. The goal is to bring a familiar and nostalgic desktop companion experience to Codex users.

## Features

* Animated QQ-style penguin companion
* Lightweight and easy to run
* Compatible with Codex Pet
* Open source and community friendly
* Customizable configuration and assets

## Installation
### Option 1: Install in codex
Attach the spritesheet.webp and pet.json to Codex and prompt Codex to add it as default pet.
Summon by prompting /pet
Select your pet choices in Appearance / Pet

### Option 2: Manual Installation

Clone the repository:

```bash
git clone https://github.com/TianjiS/qq-codex-pet.git
```

Navigate to the project folder:

```bash
cd qq-codex-pet
```

Copy the pet files into your local Codex Pet directory.

The location may vary depending on your operating system and Codex Pet installation.

After copying the files:

1. Restart Codex Pet.
2. Open the pet manager.
3. Select **QQ Codex Pet**.
4. Enable the pet.
